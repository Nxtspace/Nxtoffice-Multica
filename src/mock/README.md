# mock 数据（仅限隔离开发）

> ⚠️ **本项目所有示例数据均为 mock，不是真实 Multica 记录，不得用于验收放行。**
> 正式数据入口与最终用户授权尚未验证（ADR-01 能力缺口 ①–④）；`owner CLI` 不是生产接口。

## 用途

- 让 2D/3D 占位场景在无正式数据源时消费**同一契约版本**的快照，验证契约形状、
  状态字典、版本/过期判定与异常态表现。
- 覆盖完整状态矩阵：加载、正常、空、滞后、过期、断线（模拟）、请求错误、无权限。

## 不可伪装原则（实现约定）

1. 快照 `dataSource.kind === 'mock'`，并带 `generator` 与限制说明；
   UI 顶部**持续展示不可关闭的 mock 徽标**。
2. 所有 ID 以 `mock-` 开头，名称带「示例」；不含任何真实议题/Agent 名称或内容。
3. 演示阈值 `DEMO_THRESHOLDS`（stale 30s / expire 90s）**不是**产品批准值，
   仅用于演示三态；正式阈值待 D-2 批准后由配置注入。
4. 契约校验 `validateSnapshot` 覆写为强制项：mock 场景产物必须全部通过，
   否则视为数据缺陷（测试 `mock/scenarios.test.ts`）。

## 场景

| id | 说明 |
|---|---|
| `loading` | 连接中，无快照 |
| `normal` | 完整数据 + 脚本化增量（分派→运行→完成） |
| `empty` | 首次使用空态 |
| `stale` | 超过滞后阈值（演示值） |
| `expired` | 超过过期阈值（演示值），冻结动效 |
| `disconnected` | 收到快照后 4s 模拟掉线 |
| `error` | 快照请求失败，可重试 |
| `forbidden` | 受限用户：元数据裁剪 + 对象完全不下发 |

## 何时删除

M2 正式服务端授权适配器可用后，本目录与 mock 徽标一起移除；
在此之前，任何演示/验收材料必须明确标注 mock 来源。
