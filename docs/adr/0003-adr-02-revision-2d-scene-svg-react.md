## 六、ADR-02 修订条目文本（U1 归档时入仓，归档前请复核）

> **前提增补**：项目方已批准复用 openclaw-office-2 视觉资产（MIT；锁定 commit `be47d03`；署名链 OpenClaw/WW-AI-Lab＋artapon fork 入 THIRD-PARTY-NOTICES）。该资产为程序化 React/SVG/R3F 组件，非静态模型文件；品牌风格依赖 D-2 结论。
>
> **2D 等距场景行，替换为**：SVG + React 组件 + CSS 动画（移植 openclaw-office-2 office-2d 组件）。取舍：获批资产以 SVG 组件实现，PixiJS 无法直接消费；约 150 同屏动画对象内性能充足（CSS transform/opacity 合成器加速）；与外壳同框架、无第二图形栈。退出条件：批准规模或性能阈值超出 SVG 包络，或需粒子/滤镜级效果 → 以共享契约层为隔离面重评 Canvas/WebGL。
>
> **判据表更新**：SVG+React 4.10；PixiJS+R3F 3.85（原 4.35 基于「无既有资产」前提，该前提已失效）；全 Three.js 3.85。3D 行维持 R3F 不变。
>
> **采纳门槛增补**：U1 期间以批准规模完成 2D SVG＋3D R3F 双视图帧时间小样，作为 SVG 选型的实测确认。

其余条目（外壳、共享契约、服务端适配、验证）不受本结论影响。

## U1 落地说明（本行为新增，非原文）

- 本仓库骨架**不安装 PixiJS，也不安装 SVG 之外的 2D 渲染库**：2D 视图层以占位 `<section>` 挂位（`src/views/two-d/`），等 2D 渲染层裁定后由 U3/U4 填充。
- `docs/adr/0002` 保留 ADR-02 原文（含 PixiJS 行）不改写，与本条目并列归档；两者分歧以本条目的「退出条件」与项目方裁定为准。
- SVG+React 的实测确认（帧时间小样）在 U1 内不完成不阻塞建仓，但 2D 正式实现开工前须完成。
