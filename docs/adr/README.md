## 状态语义

| 状态 | 含义 |
|---|---|
| proposed（提议） | 已入仓，等待复核确认。**本仓库所有 ADR 当前均为 proposed**：按 NXTLAB-16 开工指令，归档后须由技术总监-orion 在本议题复核，复核未回前可入仓但**不得标记为已批准**。 |
| accepted（已采纳） | 复核通过并被项目方/技术总监书面确认。状态迁移只能由复核结果驱动，不由前端开发工程师单方面改写。 |
| superseded（被取代） | 被后续 ADR 明确取代（如 0002 的 2D 行被 0003 修订，但 0002 保留全文，仅标注关系，不改写原文）。 |

## 归档规则（本仓库约定）

1. **文本以原评论为准，不得改写技术内容。** 归档时抄录原文，仅可追加独立的「落地说明」段落并明确标注「本行为新增，非原文」。
2. **原始来源可追溯**：每条 ADR 头部登记来源议题与评论 ID（mention 链接）。
3. **状态只能上移不能自授**：proposed → accepted 需技术总监复核结论；不允许前端单方面标记已批准。
4. 新增 ADR 按编号递增，文件名 `NNNN-kebab-case.md`，并在此表登记一行。
